Hata Avcısı (Bug Hunter)

# Proje Hakkında

Hata Avcısı, HTML öğrenme sürecimde kendimi geliştirmek ve öğrendiğim bilgileri pratiğe dökmek amacıyla yaptığım bir projedir.

Bu projede, HTML kodları içerisinde bulunan çeşitli hataları inceleyerek bunların neden kaynaklandığını anlamaya ve doğru şekilde düzeltmeye çalıştım.

Karşılaştığım hataları sadece düzeltmekle kalmayıp, her hatanın ne anlama geldiğini ve neden sorun oluşturduğunu da araştırdım. Böylece HTML yapısını daha iyi anlamayı ve kod yazarken daha dikkatli olmayı hedefledim.

# Projenin Amacı

Bu projeyi yaparken temel amacım HTML bilgimi geliştirmek, kodları daha iyi analiz edebilmek ve karşıma çıkan hatalara kendi başıma çözüm üretebilmekti.

Özellikle web sayfalarında doğru HTML kullanımı ve erişilebilirlik konularına dikkat ettim.

# Kullanılan Teknolojiler

- HTML5, CSS

# Projede Neler Yaptım?

- HTML kodlarını inceleyerek eksik ve hatalı alanları tespit ettim.
- Etiketlerin doğru kullanılıp kullanılmadığını kontrol ettim.
- Eksik öznitelikleri belirleyerek gerekli düzenlemeleri yaptım.
- Görsellerde kullanılan `alt` özniteliğinin önemini öğrendim.
- Erişilebilirlik hatalarını inceleyerek çözümlerini uyguladım.
- Kod yapısını daha anlaşılır ve düzenli hale getirdim.

# Bu Projeden Neler Öğrendim?

Bu proje sayesinde HTML konusunda teorik bilgilerimi pratiğe dökme fırsatı buldum.

Özellikle bir kodda hata olduğunda doğrudan çözüm aramak yerine öncelikle hatanın nedenini anlamanın ne kadar önemli olduğunu fark ettim.

Ayrıca web erişilebilirliği, HTML öznitelikleri ve kod kontrolü hakkında yeni bilgiler edindim.

Bu proje, yazılım öğrenme yolculuğumda yaptığım çalışmalardan biridir. Henüz öğrenme aşamasındayım ve her yeni projede bilgilerimi geliştirmeyi, daha fazla pratik yapmayı ve farklı konular öğrenmeyi hedefliyorum.
